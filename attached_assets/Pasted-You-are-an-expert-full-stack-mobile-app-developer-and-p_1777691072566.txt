You are an expert full-stack mobile app developer and product architect.

Build a complete cross-platform mobile app for a dance studio brand called “Central Studio” in Egypt.

The app has two connected experiences inside one app:

1. Central Studio
For learning, browsing dance classes, booking classes, offers, schedules, payments, notifications, and user profiles.

2. Central Stage
For professional dancers to create a full professional profile and become part of a talent database for future work opportunities such as events, ads, shows, workshops, music videos, and performances.

The app must support Android and iOS. Use a clean, scalable architecture.

Recommended stack:
- Frontend: Flutter
- Backend: Firebase or Supabase
- Authentication: Email/phone OTP if possible
- Database: Firestore or Supabase PostgreSQL
- Storage: Firebase Storage or Supabase Storage
- Notifications: Firebase Cloud Messaging
- Payment integration should be prepared but can be mocked in MVP
- Admin dashboard can be prepared as backend structure or simple web panel later

Brand direction:
- Central Studio: energetic, bright, youth-focused, dance-learning experience

Important product concept:
The app starts by letting the user choose between:
- Central Studio: Learn & Book Dance Classes
- Central Stage: Professional Dancer Profile & Opportunities

This choice is NOT permanent. The user can switch between Studio and Stage later from Profile or Settings.
